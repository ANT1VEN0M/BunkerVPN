# 🐈‍⬛ БУНКЕР VPN — Официальный Android VPN-клиент

Фирменный Android-клиент для подписчиков Telegram-канала **[Бункер Кота](https://t.me/BUNKER_KOTA)**.

---

## ⚡ Особенности клиента

* **Вшитая подписка Бункера:** при установке клиент сам подгружает свежие проверенные серверы (`⚡ АВТОВЫБОР`, `Швейцария 🇨🇭`, `Нидерланды 🇳🇱`, `Россия 🇷🇺` и др.) и регулярно обновляет их в фоне.
* **Поддержка всех топовых протоколов:** VLESS Reality (XTLS Vision), VMess, Trojan, Shadowsocks, Hysteria2, WireGuard.
* **Обход блокировок без тормозов:** Сбербанк, Госуслуги, Тинькофф и российские сайты открываются напрямую на полной скорости, а YouTube, Discord, Instagram, Telegram и ChatGPT идут через защищённый туннель.
* **Сплит-туннелинг:** выбор конкретных приложений для работы через VPN.
* **Фирменный стиль Бункера:** тёмная тема, логотип с котом, прямые кнопки перехода в канал и чат.

## 🚀 Как собрать свой APK за 3 минуты через GitHub (Бесплатно)

В репозиторий уже добавлен настроенный CI/CD пайплайн (`.github/workflows/build.yml`). Вам не нужны мощный ПК или установленная Android Studio!

1. Создайте репозиторий на GitHub (например, `bunker-vpn-android`).
2. Загрузите файлы этого проекта в репозиторий:
   ```bash
   git init
   git remote add origin https://github.com/ВАШ_ЛОГИН/bunker-vpn-android.git
   git add .
   git commit -m "Initial Bunker VPN Release"
   git push -u origin master
   ```
3. Перейдите во вкладку **Actions** в вашем репозитории на GitHub.
4. Выберите workflow **Build Bunker VPN APK** и нажмите кнопку **Run workflow**.
5. Через 3-5 минут в разделе **Artifacts** (или **Releases**) появятся готовые файлы:
   * `BunkerVPN-arm64-v8a.apk` (для 99% современных Android-смартфонов).
   * `BunkerVPN-universal.apk` (универсальный для любых устройств).

Скачивайте APK и делитесь с подписчиками канала! 😻
